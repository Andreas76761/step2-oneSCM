# 11 Intern – interne Themen

Arbeitsmaterial rund um oneSCM, das **nicht für Anwendende** bestimmt ist. Inhalte aus `11_Intern` erscheinen nie im Handbuch, in `04_Output`, im Releaseletter oder in einer Übersetzung.

| Ordner | Thema |
|---|---|
| `01_Testing/` | Testkonzepte, Testfälle, Testdaten (nur anonymisiert), Ergebnisse |
| `02_Reporting/` | Berichte, Kennzahlen, Auswertungen |
| `03_Systeme/` | Systemlandschaft, Schnittstellen, Umgebungen |
| `04_Migration/` | Datenmigration, Altsysteme, Übernahmeregeln |
| `05_Rollout/` | Rollout-Planung je Markt und Sparte, Kommunikation, Schulungstermine |
| `06_Other/` | alles Interne, das in keinen der anderen Ordner passt |

Regeln:

- Je Thema eine `THEMA.md` mit der Übersicht der Dateien; eigene Dateien frei benennen.
- Datenschutz wie überall (Grundregel 4): keine Namen, E-Mail-Adressen, User-IDs, FIN oder Kundendaten.
- Fertige interne Dokumente (z. B. Redaktionsleitfaden) erstellt der ausgabe-produzent in `05_I_Output/05_Interne_Dokumente/`; Quelle ist dann `11_Intern`.
- Einträge aus der App (Bereich „Intern“) übernimmt der Abgleich als `<Titel>.md` in den passenden Themenordner.
