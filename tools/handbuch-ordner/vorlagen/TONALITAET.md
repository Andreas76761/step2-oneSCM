# Tonalität

Gilt für Kapitelentwürfe und alle Produkte in `05_I_Output`. Grammatik und Schreibweisen: `07_III_Grammatik_Synonyme_Fehlerliste/`.

## Grundregeln

| Regel | Beispiel |
|---|---|
| Anrede **„Sie“**, durchgängig | „Wählen Sie …“ |
| **Aktiv** statt Passiv | „Das System speichert den Antrag.“ statt „Der Antrag wird gespeichert.“ |
| **Kurze Sätze**, höchstens 25 Wörter, eine Aussage je Satz | |
| Präsens, Handlungsaufforderung im Imperativ | „Klicken Sie auf „Save“.“ |
| **UI-Begriffe englisch** wie in der Oberfläche, in „…“; beim ersten Auftreten deutscher Handbuchbegriff in Klammern | „Contract Proposal“ (Antrag anlegen) |
| **MO = Market Operation**; beim ersten Auftreten je Produkt ausschreiben | „Market Operation (MO)“ |
| **Sparten nur Pkw und Van** – Truck und Bus nicht verwenden | |
| Rollen: Dealer, MO, Markt, HQ, IT | |
| Sachlich, ohne Werbesprache, ohne Füllwörter („einfach“, „natürlich“, „schnell“) | |
| Keine Vermutungen: Ungeklärtes bleibt `[offen: …]` bis zur Freigabe | |

## Ton je Produktart

| Produkt | Ton | Länge | Besonderheiten |
|---|---|---|---|
| Handbuch | sachlich, vollständig, anleitend | je Unterkapitel nach Gliederung | Schritte nummeriert, Warnhinweise nach Schema |
| Releaseletter | knapp, informierend, nutzenorientiert („Was ist neu? Was bedeutet das für Sie?“) | 1–2 Seiten je Release | je Änderung: Was – Für wen (Rolle, Sparte, Markt) – Ab wann – Verweis aufs Handbuch |
| QuickGuide | direkt, auf das Nötigste reduziert | 1–2 Seiten je Rolle | nur Schritte und Screens, keine Hintergründe |
| Schulungsmaterial | erklärend, motivierend, mit Beispielen und Übungen | nach Modul | Lernziel je Modul, Wissenscheck mit Lösungen (Anhang H) |
| Interne Dokumente | präzise, fachlich, Abkürzungen erlaubt (mit Glossar) | nach Bedarf | Zielgruppe Redaktion, HQ, IT |
| Videos | gesprochen: kurze Sätze, Ansprache mit „Sie“, ruhiges Tempo | 2–5 Minuten | Sprechertext synchron zu den Bildschirmschritten |
| Grafiken | Stichworte, keine ganzen Sätze | | Beschriftung englisch für UI, deutsch für Erklärungen |
| Prozesse | neutral, Ablauf aus Sicht der Rollen | | Verben im Infinitiv in Prozessschritten („Antrag prüfen“) |

## In der App

Unter **Schreibstil › Regeln › Tonalität** steht derselbe Ton je Produktart als Vorgabe (Handbuch und Prozesse sachlich; Releaseletter, Quick Guide und Grafiken knapp; Schulung und Videos freundlich; Interne Dokumente formell), dazu ein Ton je Rolle (Dealer, Markt, MO, HQ) für Absätze genau einer Rolle. Die Regel „Tonalität“ meldet Werbesprache, Verkürzungen, Floskeln und strenge Formulierungen; die KI-Vorschläge treffen den eingestellten Ton. Weicht diese Datei von der App ab, gleichen Sie beides ab – ein Mensch entscheidet.
