# Ziel

Ein vollständiges, belegtes und freigegebenes oneSCM-Handbuch: jeder Inhalt trägt die Pflichtlabels und steht im richtigen Kapitel, jedes Kapitel zeigt Standardablauf und Ausnahmen, Fragen an alle Quellen werden belegt beantwortet – Daten bleiben lokal.

> Ziel und Sollwerte pflegt ein Mensch – hier oder in der App (Agenten › GOAL). Änderungen der Agenten nur als Vorschlag.

## Kriterien

| Kriterium | Soll | Agent |
|---|---|---|
| Chunks mit allen Pflichtlabels | ≥ 95 % | triage |
| Chunks „zu prüfen“ | ≤ 5 % | triage |
| Chunks in Kapiteln der Gliederung | ≥ 95 % | triage |
| Unterkapitel „neu“ unbestätigt | 0 | gliederungs-pfleger |
| Kapitel mit Standardablauf (HappyPath) und Ausnahmen (Edge) | ≥ 80 % | kapitel-redakteur |
| Kapitel mit Kapitelanweisung | ≥ 80 % | steuerung |
| Kapitel mit freigegebener Fassung | ≥ 80 % | pruefer |
| Antwortqualität: bestandene Testfragen | ≥ 80 % | goal |
| Produktive Pipeline-Einträge nicht übernommen | 0 | pipeline-redakteur |
| Offene Entscheidungen | 0 | orchestrator |
