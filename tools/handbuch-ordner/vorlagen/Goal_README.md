# 12_Goal – Ziel und Abgleich

Hier steht, **woran der Erfolg des Handbuchs gemessen wird**, und wie weit es ist.

| Datei | Inhalt | gepflegt von |
|---|---|---|
| `ZIEL.md` | Ziel in einem Absatz und Kriterien mit Sollwert | Mensch |
| `ABGLEICH.md` | Stand je Kriterium: Ist, Soll, erfüllt, Empfehlung, Agent – mit Verlauf | Agent goal (bzw. App per Abgleich) |
| `EMPFEHLUNGEN.md` | Empfehlungen je zuständigem Agenten | Agent goal; Übernahme als Aufgabe durch den orchestrator |

Der Agent **goal** vergleicht alle Funktionen mit dem Ziel; der **orchestrator** macht aus den Empfehlungen Aufgaben (`00_Dokumentation/Agenten/AUFGABEN.md`). Ziel und Sollwerte ändert nur ein Mensch.
