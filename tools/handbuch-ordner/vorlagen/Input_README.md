# Input

| Ordner | Zweck |
|---|---|
| `01_Eingang/` | neue Dateien hier ablegen – Unterordner erlaubt |
| `02_Zugeordnet/` | Originale nach der Zuordnung (nicht bearbeiten) |
| `03_Ausgeschlossen/` | Dubletten, fachfremde oder nicht lesbare Dateien, Grund im Protokoll |

Der input-sortierer legt Kopien bzw. Auszüge in die Kapitel unter `01_Quellen/Raw_<Jahr>` (2023–2027, Jahr des Dokumentstands).
Dateien mit personenbezogenen Daten bleiben im Eingang, bis sie anonymisiert oder freigegeben sind.
Nichts löschen – jede Bewegung steht in `00_Dokumentation/INPUT_PROTOKOLL.md`.
