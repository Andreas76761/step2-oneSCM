# 3. Benutzerverwaltung

## 3.1 Überblick

Die Benutzerverwaltung legt fest, welche Personen oneSCM nutzen dürfen und welche Daten sie sehen.

## 3.2 Freigabe

Ein Administrator muss den Benutzer freigeben, bevor der Benutzer das System nutzen kann.

- Die Freigabe ist Voraussetzung für den Zugriff.
- Ohne Freigabe ist keine Anmeldung möglich.

### Voraussetzungen

Der Benutzer ist in der Marktorganisation angelegt und einer Organisationseinheit zugeordnet.

### Vorgehen

1. Öffnen Sie **Administration › Benutzer**.
2. Wählen Sie den Benutzer aus der Liste aus.
3. Klicken Sie auf **Freigeben**.

Ergebnis: Der Benutzer erhält den Status „aktiv“ und kann sich anmelden.

Alle Änderungen werden im Änderungsprotokoll mit Datum und Benutzerkennung gespeichert.

## 3.3 Fehlerbehebung

Hinweis: Wenn der Button **Freigeben** ausgegraut ist, fehlt dem Administrator die Berechtigung zur Benutzerpflege.
