**Vertrags- und E-Mail-Vorlagen im Bereich Documents & Communications**

Im Bereich Documents & Communications können Sie Vorlagen für Verträge und E-Mails erstellen und bearbeiten. Beim Anlegen einer Vertragsvorlage füllen Sie zunächst die erforderlichen Felder aus und gestalten den Inhalt im Editor. Anschließend können Sie die Vorlage entweder als Entwurf speichern oder veröffentlichen.

Im Feld „Contract Name“ prüft das System Ihre Eingaben. Enthält der Name ungültige Zeichen oder überschreitet er die maximal zulässige Anzahl an Zeichen, erscheinen entsprechende Fehlermeldungen. Auch das Datumsfeld wird geprüft: Geben Sie einen Wert aus der Vergangenheit ein, wird eine Fehlermeldung angezeigt.

Im Editor können Sie nach einer Druckvariablen suchen und diese per Drag-and-drop in die Vorlage einfügen. Die Schaltfläche „Publish“ ist deaktiviert, solange der Editor leer ist. Erst wenn die Vorlage Inhalt enthält und alle Felder ausgefüllt sind, können Sie sie veröffentlichen. Wenn Sie noch nicht fertig sind, können Sie die Vorlage mit allen ausgefüllten Feldern als Entwurf speichern und später weiterbearbeiten.

Auch beim Erstellen oder Bearbeiten einer E-Mail-Vorlage haben Sie jederzeit die Möglichkeit, den Vorgang abzubrechen.
