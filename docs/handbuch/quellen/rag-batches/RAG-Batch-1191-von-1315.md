**Gruppierung von Coverage Codes über ein Textlabel (Family Tag)**

Beim Anlegen eines Coverage Codes steht Ihnen ein neues Feld namens „Family Tag" zur Verfügung. Damit lassen sich Coverage Codes mit ähnlicher Benennung unter einer gemeinsamen Kategorie zusammenfassen, zum Beispiel die Deckungen „Warranty Powertrain", „Warranty Vehicle" und „Warranty Residual" unter dem Label „Warranty Extension". Auf dieser Grundlage können die Coverage Codes in Ansichten für den Vertrieb oder für Kunden gruppiert dargestellt werden. Das macht die Darstellung für diese Nutzer leichter verständlich. Bisher gab es lediglich eine einfache Liste aller Coverage Codes. Die bisher einzeln geführten Coverage Codes werden nun als Coverage-Kategorie angezeigt. Die Daten werden in der Reihenfolge, die zuvor festgelegt wurde, und gruppiert nach dem Family Tag an die Generierung übergeben.

Das Feld steht den Benutzern mit der Rolle HQPM beim Anlegen eines Coverage Codes zur Verfügung. Sie erreichen die Funktion über den Admin-Bereich im Menü und dort über das entsprechende Untermenü für die Codes. Mit der Schaltfläche zum Erstellen eines Coverage Codes öffnet sich ein Pop-up, in dem der Anlageprozess in drei Schritten durchlaufen wird. Der Prozess kann jederzeit abgebrochen werden.

Im ersten Schritt, der Definition des Coverage Codes, werden die bereits bekannten Felder um das Feld „Family Tag" ergänzt. Es ist optional und wird per Texteingabe befüllt. Die Eingabe muss mindestens 3 und darf höchstens 25 Zeichen umfassen. Sonderzeichen sind erlaubt. Der Family Tag muss nicht eindeutig sein, es können also mehrere Coverage Codes dasselbe Label tragen. Werden die Vorgaben nicht eingehalten, erscheinen entsprechende Fehlermeldungen.

Im zweiten Schritt, der Marktspezifität, legen Sie die Märkte fest, in denen der Coverage Code verwendbar sein soll. Auch auf dieser Seite wird das optionale Feld „Family Tag" angezeigt. Sie können zum vorherigen oder zum nächsten Schritt navigieren oder den Vorgang beenden.

Im dritten Schritt, Übersicht und Bestätigung, werden alle in den vorherigen Schritten erfassten Angaben angezeigt. Hier können Sie zum vorherigen Schritt zurückkehren oder den Vorgang beenden. Mit der Schaltfläche zur Bestätigung wird die Konfiguration des Coverage Codes in der Übersichtsliste gespeichert. Anschließend können Sie zur Übersichtsseite der Coverage Codes wechseln und den neu angelegten Coverage Code dort einsehen.

In der Übersichtstabelle der Coverage Codes finden Sie zusätzlich die neue Spalte „Family tag". So sehen Sie auf einen Blick, welchem Label die einzelnen Coverage Codes zugeordnet sind.
