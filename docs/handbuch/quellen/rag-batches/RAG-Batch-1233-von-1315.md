**Preisversion anlegen**

In der Contract Calculation können Sie neue Preisversionen erstellen, damit die von Ihnen angelegten Preise erst ab einem bestimmten Zeitpunkt gültig sind. Rufen Sie dazu die Übersicht der Preisversionen auf und klicken Sie auf die Schaltfläche „Create Price Version“. Anschließend werden Sie auf eine neue Seite weitergeleitet, auf der Sie die Angaben zur neuen Preisversion erfassen.

Zunächst vergeben Sie einen Versionsnamen. Dieser muss mindestens 3 und darf höchstens 100 Zeichen lang sein. Wird diese Vorgabe nicht eingehalten, erscheint die Fehlermeldung „Min. 3 and max. 100 characters allowed. Please correct your input and try again“. Das Feld für das Produkt ist bereits automatisch mit dem Namen des Produkts vorbelegt, für das Sie die neue Preisversion anlegen.

Außerdem legen Sie ein Startdatum fest, das in der Zukunft liegen muss. Als Vorschlag wird standardmäßig ein Datum eine Woche nach dem aktuellen Datum vorausgewählt. Dies gilt, wenn Sie die erste Version anlegen oder wenn der Start der vorherigen Version bereits in der Vergangenheit liegt. Existieren bereits Preisversionen mit einem Startdatum in der Zukunft, ist der erste verfügbare Tag der Tag nach dem Startdatum, das am weitesten in der Zukunft liegt. Dieser Tag wird in diesem Fall als Datum vorgeschlagen.

Um die Erstellung abzuschließen, wählen Sie die Schaltfläche „Create“. Sobald Versionsname und Startdatum angegeben sind, ist diese Schaltfläche aktiv. Nach dem Klick wird die Seite geschlossen, die Daten werden gespeichert und die neue Preisversion erscheint in der Liste. Zur Bestätigung erhalten Sie die Erfolgsmeldung „"Price Version X" was successfully created“. Diese Benachrichtigung wird 15 Sekunden lang angezeigt und verschwindet danach automatisch.

Wenn Sie den Vorgang abbrechen möchten, wählen Sie die Schaltfläche „Cancel“. Die Seite wird dann geschlossen, und es werden keine Daten gespeichert.

Schlägt das Anlegen der Preisversion fehl, erscheint die Fehlermeldung „Something went wrong, and we could not create your price version. Please try again.“ Diese Benachrichtigung enthält eine Schaltfläche „Close“ und bleibt so lange sichtbar, bis Sie sie schließen.
