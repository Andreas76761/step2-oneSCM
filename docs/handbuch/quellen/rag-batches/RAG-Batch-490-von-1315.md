**Vorlagen für Dokumente und Kommunikation**

Im Bereich Documents & Communications lassen sich Vorlagen für Fußzeilen (Footer), Kopfzeilen (Header), Textblöcke (Block) sowie Allgemeine Geschäftsbedingungen (T&C) erstellen. Auf der Übersichtsseite der Dokumentvorlagen gelangen Sie über jeweils eine eigene Schaltfläche direkt zur Erstellung der gewünschten Vorlagenart. Die Übersicht bietet außerdem mehrere Hilfsmittel: Sie können nach dem Vorlagennamen suchen und die Suche anschließend zurücksetzen, über Dropdown-Felder filtern, die Spalten auf- und absteigend sortieren und festlegen, wie viele Einträge pro Seite angezeigt werden.

**Eingaben und Validierung**

Bei der Erstellung einer Vorlage tragen Sie zunächst die erforderlichen Daten ein, darunter den Namen der Vorlage (Footer-, Header-, Block- bzw. T&C-Name). Geben Sie ungültige Daten ein oder überschreiten Sie die maximal zulässige Zeichenanzahl im Namensfeld, werden entsprechende Fehlermeldungen angezeigt. Bei Blockvorlagen werden Fehlermeldungen ebenfalls bei ungültigen Eingaben im Namensfeld ausgegeben.

Die Schaltfläche „Publish“ bleibt deaktiviert, solange der Design-Editor einer Footer-, Header- oder Blockvorlage leer ist. Bei T&C-Vorlagen ist „Publish“ deaktiviert, solange kein Dokumenttyp ausgewählt wurde.

**Abbrechen der Erstellung**

Haben Sie in keinem Feld Daten eingegeben, können Sie die Erstellung einer Footer-, Header- oder Blockvorlage abbrechen, ohne dass ein Bestätigungsdialog erscheint. Haben Sie dagegen bereits Daten in allen Feldern erfasst, erscheint beim Abbrechen ein Dialog zur Bestätigung des Abbruchs. Bei Footer- und T&C-Vorlagen können Sie den Abbruch zudem wieder verwerfen. In diesem Fall bleiben die bereits eingegebenen Daten erhalten.

**Speichern als Entwurf**

Sie können eine Vorlage mit gültigen Daten als Entwurf speichern. Bei Footer-, Header- und Blockvorlagen erscheint nach dem Speichern eine Erfolgsmeldung. Die eingegebenen Daten bleiben im Entwurf erhalten. Bei T&C-Vorlagen ist dies sowohl möglich, wenn Sie einen Footer und einen Header als Editor auswählen, als auch, wenn Sie eine PDF-Datei hochladen. In beiden Fällen wird die Vorlage als Entwurf gespeichert und die Daten bleiben bestehen.

**Veröffentlichen**

Sind alle Felder ausgefüllt, können Sie die Vorlage veröffentlichen. Dies gilt für Footer-, Header- und Blockvorlagen. Bei Header- und Blockvorlagen erscheint nach der Veröffentlichung eine Erfolgsmeldung. Bei T&C-Vorlagen können Sie entweder einen Footer und einen Header als Editor auswählen oder eine PDF-Datei hochladen und die Vorlage anschließend veröffentlichen.

**Vorschau**

Bei der Footer-Vorlage steht eine Vorschau zur Verfügung, mit der Sie einen Block ansehen können.
