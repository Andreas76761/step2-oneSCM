**MPay und die Löschung von CIAM-IDs**

Im Bereich Revenue Management wird oneSCM um die Anbindung an das CID Tool erweitert, das von Mercedes Me bereitgestellt wird. Möchte ein Kunde sein Mercedes-Me-Profil löschen, wird damit auch seine CIAM-ID gelöscht. In diesem Fall fragt das CID Tool bei oneSCM an, ob die Löschung zulässig ist. oneSCM beantwortet diese Anfrage abhängig von den eigenen geschäftlichen Anforderungen.

Hintergrund ist, dass eine CIAM-ID nicht gelöscht werden soll, solange sie noch für MPay-Zahlungen benötigt wird. Um dies sicherzustellen, stellt oneSCM den Mercedes-Me-Kolleginnen und -Kollegen eine API zur Verfügung. Die technischen Details der Integration sind im zugehörigen Integrationsleitfaden beschrieben. Die Anbindung ist abgeschlossen.
