**Anpassung der Anwendung an den angemeldeten Benutzer**

oneSCM passt sich nun an den angemeldeten Benutzer an. Die Anwendung unterstützt eine Vielzahl von Märkten, darunter Deutschland, Belgien, Russland, Frankreich, Griechenland, das Vereinigte Königreich, Italien, die Niederlande, Österreich, Portugal, Polen, Rumänien, Dänemark, Schweden, die Schweiz, Tschechien, Spanien, die Slowakei, die Türkei, Ungarn, Südafrika, Kanada, die USA (MBUSA), Mexiko, Argentinien, Brasilien, Taiwan, China, Indien, Indonesien, Japan, Südkorea, Malaysia, Singapur, Thailand, Vietnam, Australien und Neuseeland. Hinzu kommt ein globaler Markt. Für fast alle Märkte stehen sämtliche Divisionen zur Verfügung. Eine Ausnahme bildet Malaysia, wo ausschließlich die Division Passenger Car verfügbar ist. Wenn einem Benutzer in Alice mehrere Märkte zugewiesen sind, etwa Indien und Deutschland, wird dies von der Anwendung berücksichtigt.

**Sprache der Benutzeroberfläche**

Die Anzeigesprache richtet sich nach einer festen Reihenfolge. Beim allerersten Aufruf von oneSCM wird zunächst die in Alice hinterlegte bevorzugte Sprache verwendet. Ist diese in oneSCM nicht verfügbar, wird die Sprache des Browsers angezeigt. Steht auch diese nicht zur Verfügung, erscheint die Anwendung auf Deutsch. Bei jedem weiteren Aufruf wird zuerst die zuletzt gewählte Sprache verwendet, danach folgen in derselben Reihenfolge Alice, der Browser und schließlich Deutsch.

Fehlen für einen Benutzer die Berechtigungen zur Nutzung von oneSCM, erscheint eine angepasste deutschsprachige Meldung. Sie lautet: „Sorry – offenbar ist etwas schief gelaufen!“ Darunter wird erklärt: „Für Sie sind keine User-Rechte zur Nutzung von oneSCM hinterlegt. Bitte wenden Sie sich an Ihren ALICE-Administrator.“

**Bedienung**

In allen Formularen lässt sich das Formular nun durch Drücken der Eingabetaste absenden. Auf mobilen Geräten werden außerdem Tooltips ausgelöst, sodass auch dort die Hilfetexte abrufbar sind.
