**Digitale Signatur (Stufe 2)**

Beim Verkauf eines Vertrags kann ein Verkäufer die Vertragsdokumente künftig auf unterschiedliche Weise unterschreiben lassen. Zur Auswahl stehen die elektronische Signatur über DSS per E-Mail und Einmalpasswort (OTP), die elektronische Signatur vor Ort auf dem Gerät des Händlers, auf dem oneSCM läuft, sowie das Ausdrucken des Dokuments zur handschriftlichen Unterschrift. Die On-Premise-Variante setzt voraus, dass das DSS-Team die Anbindung an oneSCM umsetzt.

Der Ablauf beginnt auf der Übersichtsseite im Vertragserstellungsprozess. Wenn Händler, MO oder MPC dort den nächsten Schritt bestätigen, öffnet sich nach dem Klick auf die Schaltfläche CONFIRM ein Dialogfenster mit den verfügbaren Signaturmethoden. Es kann nur eine Methode ausgewählt werden. Zusätzlich kann der Benutzer festlegen, dass zur gewählten Signaturmethode ein Papierausdruck erstellt wird. In diesem Fall wird ein Druckauftrag mit dem Service-Vertrag als PDF an den Drucker gesendet. Dieses Dokument enthält weder die MB-Signaturen noch das Entwurfswasserzeichen (DRAFT).

Wird die DSS-Signatur gewählt, löst das System die DSS-Schnittstelle aus. Der Kunde erhält eine E-Mail mit einem Link. Nach dem Öffnen des Links fordert er einen OTP-Code an, den er auf sein Mobiltelefon erhält. Sobald er den korrekten Code eingegeben hat, wird er zur Unterschrift des Dokuments weitergeleitet. Das unterschriebene Dokument wird im DSS-Archivierungssystem gespeichert. Der Händler, der den DSS-Ablauf gestartet hat, erhält eine E-Mail mit dem unterschriebenen Dokument und den zugehörigen Informationen im Nachrichtentext.

Bei der Auswahl der On-Premise-Signatur unterschreibt der Kunde persönlich vor Ort auf einem Gerät am Verkaufsort, zum Beispiel auf einem Apple iPad mit Apple Pencil. Nach der Unterschrift wird das Dokument im DSS-Archiv gespeichert und im Reiter „Communication“ angezeigt.

Wählt der Benutzer die Option „Dokument drucken“, öffnet sich der Druckauftrag, damit das Dokument ausgedruckt werden kann. Dieses Dokument enthält die MB-Signaturen.

Zusammengefasst stehen mehrere Signaturoptionen zur Verfügung, von denen nur eine ausgewählt werden kann. Die Option Papierausdruck lässt sich mit jeder Signaturmethode kombinieren. Elektronisch signierte Dokumente werden im DSS-Archiv abgelegt und nach erfolgreicher Signatur im Reiter „Communication“ angezeigt.

**Vorlagen für Datenschutzerklärungen (Privacy Policy Template)**

Auf der Seite zum Erstellen von Vorlagen für Datenschutzerklärungen ist die Schaltfläche „Publish“ deaktiviert, solange kein Dokumenttyp angegeben wurde. Der Benutzer kann in allen Feldern gültige Daten eingeben und im Editor eine Kopf- und eine Fußzeile auswählen. Anschließend lässt sich die Vorlage als Entwurf speichern.
