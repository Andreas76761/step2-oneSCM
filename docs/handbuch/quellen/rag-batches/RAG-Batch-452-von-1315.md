**Systeminterne Benachrichtigungen: Kundenrechnungen prüfen**

Im Bereich Documents & Communications stehen Ihnen systeminterne Benachrichtigungen zu Kundenrechnungen zur Verfügung. Diese Funktion ist im Einsatz. Über die Benachrichtigung können Sie eine Kundenrechnung direkt bearbeiten, indem Sie sie entweder freigeben oder ablehnen.

Wenn Sie in der Benachrichtigung auf die Schaltfläche „Approve“ klicken, wird die Rechnung von Ihnen freigegeben. Der Status der Rechnung wechselt dabei automatisch auf „accepted“. Damit ist die Rechnung als akzeptiert gekennzeichnet, und Sie müssen keine weiteren Schritte unternehmen, um den Statuswechsel auszulösen.

Wenn Sie als MO-Benutzer die Rechnung nicht akzeptieren möchten, klicken Sie auf die Schaltfläche „Reject“. Die Rechnung wird damit abgelehnt. Im Anschluss werden Sie automatisch auf eine dafür vorgesehene Seite weitergeleitet.
