**Vertriebskanal für die Händlerprovision in Preisversionen**

Wenn in einer Preisversion der Schalter für die Händlerprovision aktiviert ist, müssen Sie mindestens einen Vertriebskanal auswählen, bevor die Preisversion angelegt werden kann. Standardmäßig sind in diesem Fall alle Vertriebskanäle vorausgewählt. Ist der Schalter dagegen deaktiviert, lässt sich die Preisversion auch ohne Vertriebskanal erstellen. Die Auswahl der Vertriebskanäle können Sie jederzeit anpassen, auch bei einer aktuellen Preisversion. Wird die Händlerprovision ausgeschaltet, kann eine Preisversion, die zuvor Provision und Vertriebskanäle enthielt, weiterhin gespeichert werden. Preisversionen mit ausgewählten Vertriebskanälen können Sie duplizieren und die Vertriebskanäle der Kopie anschließend bearbeiten; ebenso können sie gelöscht werden. Bei einer Preisversion, die zu einem veröffentlichten Produkt gehört, sind die Vertriebskanäle nicht mehr änderbar. Die Provisionsberechnung berücksichtigt den jeweils ausgewählten Vertriebskanal.

**Preisversionen ohne Fahrzeuggruppe und Preiscluster**

Ein Basis-Preiscluster kann auch ohne Fahrzeuggruppe erstellt werden. Alle weiteren Preiscluster lassen sich davon über einen Faktor oder einen Prozentwert ableiten. Beim Kopieren einer Preisversion wird das Basis-Preiscluster mit übernommen. Entfernen Sie eine Fahrzeuggruppe, zeigt das System eine Warnung an.

**Automatische Benennung anhand von Filtern**

Name und Beschreibung können anhand der gesetzten Filter automatisch generiert werden. Dafür steht ein Schalter zur Verfügung, der sich ein- und ausschalten lässt und einen definierten Standardzustand hat. Schalten Sie die automatische Benennung aus und bearbeiten den Namen, können Sie einen eigenen Namen vergeben.

**Auswahl und Anzeige der Division**

Die Auswahl einer Division ist bei Kampagnen ein Pflichtfeld. Besitzt ein Benutzer ausschließlich die Rolle Vans, werden die Division-Optionen entsprechend dieser Berechtigung angezeigt. In der Tabelle wird zusätzlich eine Spalte „Division“ dargestellt. Der Division-Filter erscheint nur, wenn der Benutzer sowohl die Berechtigung für VAN als auch für PC besitzt; Benutzer mit nur einer der beiden Berechtigungen sehen ihn nicht. Wird eine Division ausgewählt, filtert das die Tabellendaten entsprechend, und die Sortierung funktioniert weiterhin.
