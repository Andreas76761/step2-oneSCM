**Beibehaltung der Filterauswahl im Admin-Bereich „Invoice"**

Bisher gingen die Filter, die Sie im Admin-Bereich unter „Invoice" gesetzt hatten, verloren, sobald Sie zu einer anderen Seite der Rechnungsliste navigierten. Dieses Verhalten wurde angepasst: Ihre Filterauswahl bleibt nun erhalten, solange Sie sie nicht selbst zurücksetzen oder ändern und solange Sie den Invoice-Bereich im Admin-Bereich nicht verlassen.

Das gilt zunächst für die Hauptfilter. Dazu zählen die Suche nach der Verarbeitungsnummer, der Rechnungsstatus, die Nummer des Rechnungsempfängers und die Vertragsnummer. Sie können einen einzelnen Filter oder mehrere Filter gleichzeitig anwenden. Nach einem Klick auf „Suchen" werden die Datensätze angezeigt, die den gewählten Filtern entsprechen. Wenn Sie anschließend auf die zweite, dritte oder eine beliebige weitere Seite der Ergebnisliste wechseln, bleiben diese Filter unverändert bestehen. Sie werden erst dann zurückgesetzt, wenn Sie die Filter neu festlegen oder den Invoice-Bereich verlassen.

Dieselbe Funktionsweise gilt auch für die weiteren Filter („Weitere Filter"). Hierzu gehören die oneSCM-Rechnungsnummer, die FI-System-Rechnungsnummer, der Dokumenttyp, der Rechnungstyp, das Rechnungsdatum von und bis, der Name des Rechnungsempfängers, die Fahrgestellnummer und das Kennzeichen. Sie können diese Filter einzeln oder gemeinsam nutzen, mit oder ohne zusätzliche Hauptfilter. Nach dem Klick auf „Suchen" erscheinen die passenden Datensätze. Auch hier bleibt die Auswahl beim Blättern durch die Ergebnisseiten jederzeit erhalten, bis Sie die Filter ändern oder den Invoice-Bereich verlassen.
