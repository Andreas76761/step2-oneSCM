**Gesperrte Fahrzeuge in der Vertragserstellung**

Bei der Erstellung eines Servicevertrags prüft das System anhand der eingegebenen Kennung, ob das Fahrzeug für den Abschluss eines Servicevertrags infrage kommt. Geprüft wird, ob das Fahrzeug gesperrt, gestohlen, verschrottet oder als Totalschaden eingestuft ist. Bisher wurde ausschließlich der Status „gesperrt“ berücksichtigt. Die Prüfung steht den Nutzergruppen PO, MO und MPC zur Verfügung; in den Abläufen werden zudem Händler genannt. Voraussetzung ist, dass die Antwort aus dem Fahrzeugmanagement die Information zum jeweiligen Status sowie eine zugehörige Fehlernummer enthält.

Trifft mindestens einer dieser Zustände zu, zeigt das System eine Fehlerseite an. Diese enthält zunächst den Hinweis „Your identifier did not return any available results“, gefolgt von einer auf den Fall abgestimmten Meldung in der Form „This vehicle is excluded from buying a service contract - Error …“. Für ein gesperrtes Fahrzeug lautet der Zusatz „Error V“, für ein gestohlenes „Error 3“, für ein verschrottetes „Error 2“ und für ein Fahrzeug mit Totalschaden „Error 8“. Treffen mehrere Kategorien gleichzeitig zu, etwa gesperrt und Totalschaden, werden die Fehlernummern in einer gemeinsamen Meldung aufgeführt und durch Schrägstriche getrennt, zum Beispiel „Error 2 / Error 3“. Solange eine dieser Meldungen angezeigt wird, kann der Nutzer den Vertrag weder erstellen noch erwerben. Gestaltung und Grafik richten sich nach dem Mercedes-Benz Workbench.

Wird eine Fahrgestellnummer als Kennung eingegeben, erfolgt die Prüfung sofort. Liegt keiner der genannten Zustände vor, wird der Vertragserstellungsprozess fortgesetzt und, sofern vorhanden, werden die passenden Preise angezeigt.

Bei Eingabe einer Auftragsnummer hängt das Vorgehen davon ab, ob dazu bereits eine Fahrgestellnummer vorliegt. Ist sie vorhanden, wird dieselbe Prüfung durchgeführt wie bei der direkten Eingabe einer Fahrgestellnummer: Bei einem Treffer erscheint die passende Fehlermeldung, andernfalls wird der Prozess fortgesetzt. Ist der Auftragsnummer noch keine Fahrgestellnummer zugeordnet, kann der Vertrag zunächst bis zum Status „Confirmed“ erstellt werden und verbleibt in diesem Status, bis die Fahrgestellnummer vorliegt. Sobald sie verfügbar ist, wird derzeit ausschließlich geprüft, ob das Fahrzeug gesperrt ist. Die Prüfungen auf gestohlen, verschrottet und Totalschaden entfallen in diesem Fall vorerst. Ist das Fahrzeug gesperrt, wird der Vertrag abgelehnt und eine Benachrichtigung gemäß der Funktion „HQ Locked Vehicle“ versendet. Ist es nicht gesperrt, wird die Vertragsaktivierung fortgesetzt.

Auch bei Verwendung eines Baumusters als Kennung greift die Prüfung. Zunächst werden die Produkte abgerufen und konfiguriert, anschließend wird eine Kennung ergänzt, um fortzufahren. Wird dabei eine Fahrgestellnummer eingegeben, wird das Fahrzeug sofort auf die genannten Zustände geprüft und bei einem Treffer die entsprechende Fehlermeldung angezeigt. Wird eine Auftragsnummer eingegeben, gelten dieselben Regeln wie oben beschrieben: Mit vorhandener Fahrgestellnummer wird sofort geprüft, ohne Fahrgestellnummer läuft die Vertragserstellung bis zum Status „Confirmed“, und nach Eingang der Fahrgestellnummer wird nur noch auf den Status „gesperrt“ geprüft.
