**Bessere Prüfung von Druckvariablen in der Vorlagenverwaltung**

In der Vorlagenverwaltung können Druckvariablen frei eingegeben oder aus externen Quellen, aus E-Mails oder aus anderen Dokumenten hineinkopiert werden. Dabei können Tippfehler oder Kopierfehler entstehen. Die Folge ist, dass Werte nicht ausgegeben werden, obwohl sie im System vorhanden sind. Bisher mussten Anwender fehlerhafte Variablen mühsam selbst suchen, indem sie die gesamte Vorlage durchgingen.

Künftig wird beim Speichern einer Vorlage geprüft, ob alle im Editor verwendeten Druckvariablen zu den für diese Vorlage vordefinierten Variablen passen. Ist das nicht der Fall, erscheint die Meldung „Unavailable print variable(s): Please correct the template using the print variables available in the editor“. Die fehlerhaften Variablen werden zusätzlich rot hervorgehoben, damit sie schnell erkannt und korrigiert werden können. Solange die Fehler nicht behoben sind, lässt sich die Vorlage nicht speichern. Die Prüfung gilt sowohl für Dokumentvorlagen als auch für E-Mail-Vorlagen. Das Ziel ist, die Kennzeichnung falscher Variablen über Märkte und Sprachen hinweg einheitlich zu gestalten. Die Funktion richtet sich an die Nutzergruppen HQ und MPC. Dieser Punkt befand sich zuletzt im Status QG-IT.
