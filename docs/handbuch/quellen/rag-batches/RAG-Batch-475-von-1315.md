**Fußzeilen-Vorlagen erstellen (Documents & Communications)**

Im Bereich Template Management können Sie Fußzeilen-Vorlagen anlegen, die anschließend bei der Erstellung von E-Mail-Vorlagen verwendet werden. Voraussetzung ist, dass Sie sich mit den passenden Zugangsdaten angemeldet haben, auf den Reiter „Notification“ wechseln und dort über „Create Templates“ die Option „Footer“ auswählen. Sie gelangen daraufhin auf die Seite zum Erstellen einer Fußzeilen-Vorlage. Dort geben Sie zunächst die Angaben zum Template Setup und zu den Template Details ein und gestalten anschließend den Inhalt der Vorlage. Fußzeilen-Vorlagen sind vom Typ STATIC, Druckvariablen werden daher nicht benötigt.

Pflichtfelder sind der Vorlagenname, der Markt und das Gültig-ab-Datum. Der Vorlagenname ist ein Texteingabefeld mit maximal 56 Zeichen. Geben Sie mehr als 56 Zeichen ein, wird eine Fehlermeldung angezeigt. Das Feld „Markt“ ist eine Auswahlliste, deren Werte von Ihrer Benutzerrolle abhängen (derzeit Germany). Das Feld „Valid From“ ist ein Datumsfeld im Format dd.mm.yyyy. Es erlaubt keine Daten in der Vergangenheit, sondern nur das aktuelle Datum und zukünftige Daten. Anhand des Datums werden die Vorlagen in der Auswahlliste in der Reihenfolge des nächstliegenden Datums angezeigt.

Optional können Sie Division und Sprache auswählen. Bei der Division steht im MVP-Umfang PC (Passenger Car, also Pkw) zur Verfügung, VAN folgt erst nach dem MVP. Die Sprache richtet sich nach der Rolle Ihres Marktes, im MVP ist dies Englisch. Das Attribut „Brand“ wurde aus dem gesamten Template Management entfernt. Wo es zutrifft, lautet die Reihenfolge der Attribute Division, Product, Language.

Den Inhalt der Fußzeile gestalten Sie im WYSIWYG-Editor. Dort können Sie Text eingeben oder einfügen. Der Editor muss hinsichtlich der Schriftart gemäß dem Mercedes-Benz-Styleguide für E-Mails formatiert sein, und die Fußzeile soll den MB-Richtlinien für E-Mail-Fußzeilen entsprechen.

Für die Bearbeitung stehen drei Schaltflächen zur Verfügung. Mit „Save as Draft“ speichern Sie die Vorlage als Entwurf; dafür muss lediglich der Vorlagenname ausgefüllt sein. Ein Entwurf wird 30 Tage lang aufbewahrt und kann in dieser Zeit bearbeitet werden, danach wird er gelöscht. Mit „Publish“ erstellen Sie die Vorlage endgültig. Mit „Cancel“ brechen Sie den Vorgang ab: Haben Sie in einem Feld oder im Design-Editor bereits Daten eingegeben, erscheint eine Warnung vor Datenverlust. Wählen Sie dort „Cancel“, wird nur der Dialog geschlossen. Wählen Sie „Proceed“, werden die Daten nicht gespeichert und Sie kehren zur vorherigen Seite zurück. Wurden keine Daten eingegeben, gelangen Sie direkt zur vorherigen Seite.

Nach der Veröffentlichung steht die Fußzeile anhand ihrer Parameter im Auswahlfeld „Footer“ des WYSIWYG-Editors zur Wiederverwendung zur Verfügung.
