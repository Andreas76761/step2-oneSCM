**Suche nach Baumaster (Model Code) in der Fahrzeuggruppenverwaltung**

In der Verwaltung der Fahrzeuggruppen (Manage Vehicle Groups) konnten Fahrzeuggruppen für Pkw (Passenger Cars, PC) und Transporter (Vans) bisher nur über die zugeordneten Produkte, die Preisversion (die sich aus den zugeordneten Produkten ableitet) oder den Fahrzeuggruppennamen gesucht werden. Eine direkte Suche über den Baumaster (Model Code) war nicht möglich. Wer herausfinden wollte, in welchen Fahrzeuggruppen ein bestimmter Baumaster enthalten ist, musste sich manuell durch die einzelnen Dimensionen navigieren, was zeitaufwendig und ineffizient war. Die neue Funktion richtet sich an die Rollen MO/MPC.

Um dies zu vereinfachen, steht in der Verwaltung der Fahrzeuggruppen nun ein zusätzlicher Reiter mit der Bezeichnung „Search Model Code“ zur Verfügung. Er befindet sich neben den Reitern „Passenger Cars“ und „Vans“. Nach einem Klick auf diesen Reiter wird ein Dropdown-Menü angezeigt, in dem Sie zwischen „Passenger Cars (PC)“ und „Vans“ wählen können.

Unabhängig von Ihrer Auswahl wird anschließend ausschließlich das Feld „Model Code“ als Einfachauswahl angezeigt. Es muss befüllt werden, und es kann jeweils nur ein Baumaster gleichzeitig gesucht werden. Nach dem Ausführen der Suche zeigt das System die Ergebnisse in einer Tabelle an. Diese enthält die Spalten Model Code, Vehicle Group, Cluster Name, Price Version und Product Name. Bei Vans wird zusätzlich der SA Code angezeigt. Die dargestellten Daten geben die Beziehung und Zuordnung zwischen Model Code, Fahrzeuggruppe, Produkt, Cluster, Preisversion und SA Code korrekt wieder.

Wird ein ungültiger oder nicht vorhandener Model Code eingegeben, zeigt das System die Meldung „No Records Found.“ an.

Die neue Suche verbessert die Benutzerfreundlichkeit, vereinfacht Suchvorgänge und erleichtert den Zugriff auf die Daten im Modul zur Verwaltung der Fahrzeuggruppen.
