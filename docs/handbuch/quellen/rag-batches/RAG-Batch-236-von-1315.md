**Anpassung des Zahlungsplans bei Kündigung eines Vertrags innerhalb der Kündigungsfrist**

Wird ein Vertrag innerhalb der Kündigungsfrist gekündigt (Vertragsstatus „Cancelled"), passt das System den Zahlungsplan automatisch an. Welche Anpassung erfolgt, hängt vom Status der MPPI-Rechnung ab.

Befindet sich die MPPI-Rechnung zum Zeitpunkt der Kündigung im Status „Planned", wurde sie noch nicht an das FI-System exportiert. Sie wird deshalb direkt storniert, ohne dass weitere Schritte nötig sind. Der Rechnungsstatus wechselt von „Planned" auf „Cancelled". Dasselbe gilt für eine MPPI-Rechnung im Status „Accepted": Auch sie ist noch nicht an das FI-System exportiert worden und wird direkt von „Accepted" auf „Cancelled" gesetzt.

Etwas anders verläuft der Prozess, wenn die Rechnung bereits exportiert wurde. Bei der Aktivierung eines Vertrags wird die MPPI-Rechnung erzeugt und erhält den Status „Planned". Mit dem nächsten Batch-Lauf von CFDM wechselt sie auf „Accepted". Mit dem nächsten Batch-Lauf von NacosE169 wird sie zur Verbuchung an Nacos gesendet (Status „Exported"). Nacos verarbeitet die Rechnung, und oneSCM erhält als Rückmeldung, dass ein FI-Dokument erstellt wurde. Wird der Vertrag nun innerhalb der Kündigungsfrist gekündigt, erstellt das System automatisch eine Gutschrift für den Kunden mit demselben Nettobetrag wie die Rechnung, um den Kunden zu entschädigen. Die Gutschrift wird im Reiter „Price reduction" mit folgenden Angaben angelegt: Flow type „Periodically payment", oneSCM-Rechnungsnummer entsprechend der ursprünglichen Rechnung, Processing Number ohne Wert (NULL), Document Type „Credit", Status „Created" und Customer Invoice Type „MPPI". Der Rechnungszeitraum reicht vom Startdatum bis zum Enddatum des Vertrags. Der Nettobetrag entspricht dem Betrag der MPPI-Rechnung, und als Rechnungsempfänger wird der Kundenname eingetragen.

Hat das MO-Team die exportierte Rechnung in oneSCM manuell auf „Paid" gesetzt und wird der Vertrag anschließend innerhalb der Kündigungsfrist gekündigt, erstellt das System ebenfalls automatisch eine Gutschrift mit demselben Nettobetrag. Der Hintergrund: Der Prozess in Nacos ist in diesem Punkt manuell, da keine eigene Rückmeldung darüber eingeht, ob der Kunde die Rechnung beglichen hat (Status „Paid"). Das MO-Team muss daher selbst einschätzen, ob eine Gutschrift erstellt werden muss. Da Gutschriften genehmigt werden müssen, ist dies durch den erforderlichen Genehmigungsschritt abgedeckt. Die Gutschrift wird hier mit folgenden Angaben angelegt: Flow type „Periodically payment", oneSCM-Rechnungsnummer entsprechend der ursprünglichen Rechnung, Status „Accepted", Processing Number ohne Wert (NULL), Document Type „Credit" und Customer Invoice Type „MPPI". Rechnungszeitraum (Start- bis Enddatum des Vertrags), Nettobetrag (wie die MPPI-Rechnung) und Rechnungsempfänger (Kundenname) werden wie oben beschrieben befüllt.

**Anpassung des Zahlungsplans bei Aussetzung (Suspension) eines Vertrags**

Bisher wurde der Zahlungsplan bei einer Aussetzung des Vertrags nicht angepasst. Ist ein Vertrag nicht aktiv, etwa weil sein Status „Suspended" lautet, wird der Zahlungsplan nun entsprechend angepasst. War ein Vertrag für die vergangenen „n" Monate ausgesetzt, werden alle in diesem Zeitraum geplanten Rechnungen angehalten und dem Kunden für diese „n" Monate nicht in Rechnung gestellt.

Sobald der Vertrag wieder den Status „Active" erhält, wird er für den nächsten Abrechnungszeitraum beim nächsten CFDM-Lauf wieder in die Abrechnung einbezogen. Die Rechnungen der „n" Monate wechseln dabei im Zahlungsplan des Vertrags beim CFDM-Batch-Lauf von „Planned" auf „Accepted". Wie die Rechnungen an Nacos übergeben werden, hängt vom Kennzeichen für die Sammelrechnung ab. Steht es auf „Included", wird beim nächsten E169-Export an Nacos eine Sammelrechnung für diese „n" Monate gesendet. Steht es auf „Excluded", werden beim nächsten E169-Export stattdessen Einzelrechnungen für diese „n" Monate an Nacos gesendet.
