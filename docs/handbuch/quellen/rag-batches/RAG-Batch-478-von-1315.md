**Dokumente & Kommunikation: Änderungen und Korrekturen**

Im Bereich Dokumente & Kommunikation wurden mehrere Fehler behoben und Anpassungen vorgenommen, die vor allem die Vorlagen für Allgemeine Geschäftsbedingungen (AGB) und für E-Mails betreffen.

**AGB-Vorlagen**

Wenn eine AGB-Vorlage zunächst mit dem Editor erstellt wurde und anschließend der Dokumenttyp von „Editor“ auf „Upload“ umgestellt wird, trat beim Speichern bisher ein Fehler auf. Dieses Verhalten wurde korrigiert. Außerdem wurde ein Problem bei der Veröffentlichung behoben: Wurde für eine AGB-Vorlage eine PDF-Datei hochgeladen und wurden alle Pflichtfelder ausgefüllt, reagierte die Schaltfläche zum Veröffentlichen nicht, und es erschien keine Fehlermeldung. Die Vorlage ließ sich dadurch nicht veröffentlichen. Auch dies funktioniert nun wie vorgesehen. Darüber hinaus wurde ein Fehler beim Einlesen von Bildern aus Bausteinvorlagen (Block Templates) behoben.

**E-Mail-Benachrichtigungen**

Beim Verwendungszweck von E-Mail-Benachrichtigungen wurde die Bezeichnung „Cancellation“ (Stornierung) durch „Rejection“ (Ablehnung) ersetzt. Entsprechend wurde auch der zugehörige Auslöser im Status der Vertragserstellung von „CANCEL“ auf „REJECT“ geändert. Der Hintergrund: Der Verwendungszweck „Cancellation“ wird künftig für Verträge aus dem Vertragsmanagement verwendet, die aktiv sind und für die eine Kündigungs- bzw. Stornierungsaktion (CANCEL) ausgeführt wird.

**E-Mail-Vorlagen erstellen**

Für das Erstellen von E-Mail-Vorlagen wurde der gesamte Ablauf geprüft, und die folgenden Verhaltensweisen sind abgedeckt.

Beim Anlegen oder Bearbeiten einer E-Mail-Vorlage können Sie alle Pflichtfelder und optionalen Felder mit gültigen Daten füllen. Beim Klick auf „Als Entwurf speichern“ erscheint eine Hinweismeldung (Toast-Meldung). Sie können das Erstellen oder Bearbeiten jederzeit abbrechen. Eine fertige Vorlage lässt sich veröffentlichen. Entwürfe von E-Mail-Vorlagen werden nach 30 Tagen automatisch gelöscht.

Über die Schaltfläche „Test-E-Mail senden“ öffnet sich ein Dialogfenster. Geben Sie dort eine ungültige E-Mail-Adresse ein, wird eine Fehlermeldung angezeigt.

Für die Eingabefelder gelten Prüfregeln. Im Namensfeld der E-Mail-Vorlage sind neben Buchstaben und Ziffern nur die Sonderzeichen „-“, „_“, „/“ und „+“ erlaubt. Andere Sonderzeichen führen zu einer Fehlermeldung. Ebenso erscheint eine Fehlermeldung, wenn der Name länger als 56 Zeichen ist. Im Betreff-Feld führen mehr als 75 Zeichen zu einer Fehlermeldung. Druckvariablen (Print Variables) können Sie im Betreff-Feld ohne Fehlermeldung eintragen. Wird ein Wert aus der Vergangenheit eingegeben, erscheint ebenfalls eine Fehlermeldung.
