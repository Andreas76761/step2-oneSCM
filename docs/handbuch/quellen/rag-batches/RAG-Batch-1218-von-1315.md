**Contract Calculation – Preisgestaltung und Produktverwaltung**

Im Bereich Preisgestaltung der Vertragskalkulation (Contract Calculation) wird das Verhalten von Clustern innerhalb einer Preisversion geprüft. Für das erste Cluster einer Preisversion wird der Schalter nicht angezeigt. Wird dieses erste Cluster dupliziert, erscheint beim Duplikat dagegen der RBPC-Schalter. Sobald ein Cluster referenziert wird, lässt es sich nicht mehr löschen. Dieser Punkt befindet sich bereits im Einsatz. Außerdem werden für die Preismatrix mit Preisfaktor die Eingabegrenzen des RBPC-Preisfaktors geprüft.

In der Produktübersicht der Vertragskalkulation werden die Suche und die Seitenaufteilung (Paginierung) geprüft. Beim Anlegen eines Produkts wird zudem der Negativfall bei doppelten Namen getestet, also das Verhalten, wenn ein bereits vergebener Name erneut verwendet wird.
