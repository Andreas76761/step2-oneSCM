**Fahrzeuggruppen: Baumuster suchen und zu einer Fahrzeuggruppe hinzufügen**

Auf der Navigationsebene „Baumuster suchen" können Sie Baumuster (BM6) einer Fahrzeuggruppe zuordnen. Rufen Sie dazu die Navigationsebene auf, geben Sie Ihre Suchkriterien in die Eingabefelder ein und/oder wählen Sie Werte aus den verfügbaren Filtern. Mit einem Klick auf die Schaltfläche „Search for Baumusters" werden die Ergebnisse in einer Tabelle angezeigt.

Die Schaltfläche „Add to Vehicle group" wird aktiv, sobald Sie mindestens ein noch nicht zugeordnetes BM6 ausgewählt haben. Baumuster, die bereits einer Fahrzeuggruppe zugeordnet sind, werden ausgegraut dargestellt und können (für dasselbe Produkt) keiner weiteren Gruppe zugewiesen werden. Ein Klick auf die Schaltfläche öffnet ein Pop-up mit einer alphabetisch sortierten Liste aller angelegten Fahrzeuggruppen. Jede Gruppe wird als Radiobutton angeboten, es kann also nur eine Gruppe gleichzeitig gewählt werden. Standardmäßig ist der erste Eintrag der Liste vorausgewählt. Ist noch keine Fahrzeuggruppe vorhanden, erscheint anstelle der Liste der Hinweis „Please create first a vehicle group". Zusätzlich stehen die Schaltflächen „Cancel" und „Add" zur Verfügung.

Wenn Sie eine Gruppe ausgewählt haben und auf „Add" klicken, werden die gewählten Baumuster dieser Fahrzeuggruppe zugeordnet und das Pop-up wird geschlossen. Bei Erfolg erscheint eine Erfolgsmeldung, die die Anzahl der zugeordneten Baumuster und den Gruppennamen nennt, zum Beispiel: „7 selected baumusters were assigned to "Vehicle Group 2"". Schlägt die Zuordnung fehl, wird stattdessen eine Fehlermeldung angezeigt: „Selected baumusters could not be assigned to "Vehicle Group 2"". Wenn Sie „Cancel" wählen, wird das Pop-up geschlossen und die Fahrzeuggruppen bleiben unverändert. Ihre Auswahl bleibt dabei erhalten, sodass Sie weitere Baumuster auswählen können. Sie kehren zur Ergebnisseite der Baumustersuche zurück.

Die Oberfläche entspricht der Mercedes-Benz Workbench und dem vom Kunden freigegebenen UI-Design.
