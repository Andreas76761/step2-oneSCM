**Cost Management**

**Schadencodes in der Werkstattrechnung:** Market-Operation-Anwender (MO) können im Vertragsmanagement auf dem Reiter „Payment" eine Werkstattrechnung anlegen. Diese enthält einen Coverage Code und einen Damage Code. Bisher musste zuerst der Coverage Code gewählt werden, da das Feld für den Damage Code erst danach aktiv wurde. Um die Erfassung zu vereinfachen, kann der Damage Code nun unabhängig von der Auswahl des Coverage Codes eingetragen werden. Das Feld für den Damage Code ist ein Dropdown mit allen Damage Codes des Marktes und verfügt über eine Suchfunktion. Diese durchsucht sowohl den Damage Code als auch dessen Beschreibung. Ergebnisse werden angezeigt, sobald mindestens drei Zeichen eingegeben wurden. Der Damage Code ist ein Pflichtfeld. Der Coverage Code ist ebenfalls ein Pflichtfeld. Wird er vor dem Damage Code gewählt, verhält sich das Feld wie bisher und bietet alle Coverage Codes des Marktes an. Wird zuerst der Damage Code gewählt, enthält das Dropdown nur die Werte, die zum gewählten Damage Code passen. Angezeigt werden der Coverage Code und die zugehörige Coverage-Referenz, zum Beispiel „P001 - Maintenance" oder „P002 - Tire".

**Import von Schadensfällen (Claims) für mehrere Verträge:** Beim Import einer i156-Datei wurden bisher Fälle nicht abgedeckt, in denen ein Claim Coverages aus mehreren Verträgen enthält. Künftig wird ein solcher Claim beim Import auf die einzelnen Verträge aufgeteilt und dem jeweils passenden Vertrag zugeordnet. Erkannt wird ein solcher Claim daran, dass dieselbe VEGA-Claim-Nummer (Record Type 10 oder 20, Position 031 bis 039) vorliegt, mehrere Datensätze vom Typ 20 vorhanden sind und diese unterschiedliche Vertragsnummern (Record Type 20, Position 110 bis 124) enthalten. Ein Claim mit verschiedenen Coverage Codes wird so in mehrere Claims je Vertrag aufgeteilt. Die zugehörige Werkstattrechnung erscheint jeweils im Reiter „Workshop Invoices".

**Vorlage für den Import von Damage Codes:** Damit HQ-Anwender Dateien mit Damage Codes ohne Validierungsfehler importieren können, steht eine Dateivorlage bereit. Sie finden diese unter Admin-Bereich, VEGA Codes, Damage Codes. Nach einem Klick auf „Upload" öffnet sich ein Fenster mit der Schaltfläche „Download Template" und dem Hinweis, die Vorlage zu verwenden, um Validierungsfehler zu vermeiden. Durch den Klick wird eine .xlsx-Datei heruntergeladen, deren Struktur der Ergebnistabelle der Damage Codes in der Oberfläche entspricht. Der Import verarbeitet diese Struktur. Der Coverage Code muss vier Zeichen lang sein (zum Beispiel P001, P002) und wird eins zu eins in die Datenbank übernommen. Die Ergebnistabelle enthält zusätzlich die neue Spalte „Coverage Code".

**Internationale Werkstattrechnungen annehmen oder stornieren:** Manuell angelegte internationale Werkstattrechnungen werden im Admin-Bereich auf der Seite „Invoice" wie andere Rechnungen angezeigt. MO-Anwender können sie genehmigen oder stornieren. Die Genehmigung darf nicht durch den Anwender erfolgen, der die Rechnung angelegt hat. Für diese Rechnungen stehen die Aktionen „View" sowie „Approve" und „Cancel" zur Verfügung. Beim Anlegen einer Rechnung wird eine Benachrichtigung an die MO-Anwender gesendet, analog zu manuell angelegten Kundenrechnungen (MANU). Ein Klick auf die Benachrichtigung führt direkt zur Seite zum Genehmigen oder Stornieren. „Accept" ist für Rechnungen im Status „Created" verfügbar. Nach dem Klick erscheint ein Bestätigungsfenster: „Cancel" schließt es, „Confirm" setzt den Status auf „Accept" und schließt es ebenfalls. „Cancel" ist für Rechnungen im Status „Created" und „Accepted" verfügbar und öffnet ebenfalls ein Bestätigungsfenster. In den Rohdaten ist angegeben, dass „Confirm" dort den Status auf „Accept" setzt. Das wirkt wie ein möglicher Fehler in der Vorlage und sollte vor Veröffentlichung fachlich geprüft werden.
