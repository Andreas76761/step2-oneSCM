Reifenoptionen für Van Unlimited: Coverage Codes und Technische Optionen

Mit Van Unlimited lässt sich ein Reifenprodukt anlegen und verkaufen, entweder eigenständig oder als Option, die an ein bestehendes Produkt angehängt wird. Bisher gab es ein Reifenprodukt nur in einer eingeschränkten Version mit einer minimalen und maximalen Reifenanzahl. Zwei Erweiterungen schaffen nun die Grundlage für das neue Angebot: eine zusätzliche Kategorie bei den Coverage Codes und eine neue Gruppenart bei den Technischen Optionen.

Coverage Codes für Reifenoptionen

Im Bereich „Vega Code“ können Sie wie gewohnt einen neuen Coverage Code anlegen. Der Ablauf bleibt unverändert, allerdings steht in der Auswahlliste „Kategorie“ nun zusätzlich die fest hinterlegte Kategorie „Tire Option“ zur Verfügung. Diese Kategorie erscheint dauerhaft in der Liste. Alle übrigen Felder füllen Sie wie bisher aus.

Für den Coverage Code selbst gelten bei der Kategorie „Tire Option“ besondere Regeln: Der Code muss genau vier Zeichen lang sein und mit dem Buchstaben T beginnen, zum Beispiel T001. Ein Code, der im System bereits vergeben ist, kann nicht erneut verwendet werden; in diesem Fall erscheint die bereits bekannte Fehlermeldung. Anschließend schließen Sie den Vorgang ab und speichern den Coverage Code. In Übersichten und Listen, die Coverage Codes und ihre Kategorien anzeigen, ist „Tire Option“ als Kategorie sichtbar und lässt sich zum Filtern nutzen.

In der Produktdefinition verhält sich eine Coverage der Kategorie „Tire Option“ ähnlich wie eine Coverage der Kategorie „Body“. Innerhalb eines Service-Contract-Produkts kann sie nicht als „Immer enthalten“ festgelegt werden, sondern ausschließlich als „Optional“ oder „Ausgeschlossen“. Die so angelegten Coverage Codes können Sie anschließend in der Produktdefinition eines Service-Contract-Produkts verwenden, das Teil eines komplexen Produkts ist. Ein komplexes Produkt ist dabei ein Service-Contract-Produkt, bei dem Reifen eines Lieferanten als optionale Coverage enthalten sind.

Technische Optionen mit der Gruppenart „Wheel Size“

Im Bereich Fahrzeugverwaltung unter „Technische Optionen“ können Sie Technische Optionen anlegen und verwalten, die später zur Erstellung und zum Verkauf eines Reifenprodukts dienen. Beim Anlegen einer Technischen Option steht Ihnen die neue, fest hinterlegte und dauerhaft verfügbare Gruppenart „Wheel Size“ zur Verfügung.

Für eine Gruppe dieser Art vergeben Sie einen frei wählbaren Namen, beispielsweise „195/65 R17“. Das Feld akzeptiert Ziffern, Buchstaben, Leerzeichen und Sonderzeichen wie „/“ oder „R“ und ist auf maximal 35 Zeichen begrenzt. Das System speichert den eingegebenen Namen unverändert. Es sind etwa 25 verschiedene Reifengrößen denkbar.

Anschließend wählen Sie die Matching-Logik aus und speichern sie; es stehen dieselben Optionen zur Verfügung wie bei anderen Arten Technischer Optionen. Werden dabei zwei unterschiedliche Größen zugeordnet, wird die größere Größe verwendet. Zum Schluss tragen Sie wie gewohnt die SA-Codes ein. Die so definierten Technischen Optionen vom Typ „Wheel Size“ können später bei der Konfiguration von Reifenprodukten und deren Preisgestaltung verwendet werden.
