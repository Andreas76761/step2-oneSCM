Die Unterschrift kann dabei wahlweise per elektronischer Signatur (Esignature), über DSS oder über die Methode „Dokument drucken" erfasst werden. Für jede dieser drei Methoden wird der Ablauf geprüft, wenn die Kartendaten erfasst werden und die CAS-Prüfung negativ ausfällt. Ebenso wird der Fall geprüft, dass bei einer Unterschrift per Esignature keine Kartendaten erfasst werden und die CAS-Prüfung entweder einen positiven Treffer (Positive Hit) oder einen Fehltreffer (False Hit) liefert. Zusätzlich wird für alle drei Unterschriftsmethoden das Verhalten untersucht, wenn die Erfassung von Unterschrift und Kartendaten fehlschlägt und der Vorgang über „Erneut versuchen" wiederholt wird, während die CAS-Prüfung negativ ist. Diese Prüfungen befinden sich derzeit im Review.
