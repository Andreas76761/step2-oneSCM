Mehrere Bankverbindungen pro Kunde

Bisher konnte in oneSCM jedem Kunden genau eine Bankverbindung zugeordnet werden. Künftig können einem Kunden mehrere Bankverbindungen zugeordnet werden. Endkunden erhalten damit die Flexibilität, auf einem von ihnen gewählten Konto abgerechnet zu werden: Sie können beim Kauf eines Servicevertrags (SC) eine vorhandene Bankverbindung auswählen oder eine neue hinzufügen. Außerdem können sie jedem ihrer aktiven Verträge eine andere Bankverbindung zuweisen. Die Funktion wirkt sich auf die Vertragserstellung, die kundenseitige Oberfläche und die Kundenverwaltung aus. Aktualisierte Details werden zudem an Management und Revenue weitergegeben. Voraussetzung ist, dass der Kunde aktive Verträge in oneSCM hat und mindestens eine Bankverbindung den Status „ACTIVE“ besitzt.

Beim Kauf eines weiteren Servicevertrags erkennt das System einen bestehenden Kunden, und seine Daten sind vorausgefüllt. Es zeigt ihm eine Liste seiner aktiven Bankverbindungen zur Auswahl an. Ist bereits ein Hauptkonto für alle Verträge festgelegt, wird dessen Optionsfeld vorausgewählt, andernfalls bleibt die Auswahl leer. Der Kunde kann für den laufenden Servicevertrag auch eine neue Bankverbindung hinzufügen. Dafür öffnet sich ein Modalfenster, in dem er zuerst die IBAN eingibt. Die übrigen Felder kann er nicht selbst bearbeiten. Sie werden erst angezeigt, nachdem die Validierung über die Swift-Referenz-API die Werte geliefert hat. Die Schaltfläche „Confirm“ bleibt deaktiviert, solange SEPA nicht den Wert „TRUE“ hat. Nach Eingabe einer neuen IBAN erhält die Bankverbindung den Status „ENTERED“, und das Optionsfeld der neu eingegebenen IBAN ist automatisch aktiviert. Der restliche Ablauf bleibt unverändert, und die neu hinzugefügte IBAN wird wie bisher mit dem FI-System synchronisiert.

In der Kundenverwaltung kann ein Mitarbeiter (MO) auf Wunsch des Kunden eine Bankverbindung hinzufügen und festlegen, welche Verträge damit bezahlt werden sollen. Über die Konfiguration „Bankverbindung mit bereits aktiven Verträgen verknüpfen“ öffnet sich ein Modalfenster, in dem alle oder einzelne Verträge ausgewählt werden können. Nach der Auswahl prüft das System über einen Aufruf an Revenue, ob die Bedingungen erfüllt sind, und zeigt eine Meldung mit dem Datum (TT/MM/JJJJ), ab dem die IBAN gültig ist. Bei Verträgen im Status „ACTIVE“ erfolgt diese Prüfung direkt. Bei Verträgen im Status „To be confirmed“ wird zusätzlich die Bedingung von sieben Arbeitstagen geprüft. Gleiches gilt für den Status „Entered“. Hier wird außerdem über das FI-System die SEPA-Information zur IBAN abgeglichen.

Auch Kunden selbst können in der kundenseitigen Oberfläche Änderungen vornehmen. Sie können neue Bankverbindungen hinzufügen und bestehenden aktiven Verträgen zuweisen. Dabei muss der Kunde das SEPA-Mandat öffnen und lesen, andernfalls bleibt „Confirm“ deaktiviert. Auch hier muss SEPA den Wert „TRUE“ haben. Die Verknüpfung mit Verträgen und die Anzeige des Gültigkeitsdatums verlaufen nach denselben Regeln wie in der Kundenverwaltung.

Bankverbindungen lassen sich löschen, jedoch nur im Status „ACTIVE“ oder „ENTERED“. Im System muss stets mindestens eine IBAN aktiv bleiben. Wird eine aktive IBAN gelöscht, muss daher eine neue IBAN an ihre Stelle treten.

Das angezeigte Gültigkeitsdatum richtet sich nach den genannten Bedingungen und nach dem Batch-Job für das Rechnungsdatum in Revenue. Bis aktive Verträge mit einer neu hinzugefügten Bankverbindung verknüpft sind, behält diese den Status „ENTERED“.
