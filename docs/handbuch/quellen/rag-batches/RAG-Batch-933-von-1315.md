**Massenerfassung von Fahrzeugen: Zusätzliche Anpassungen beim Hinzufügen mehrerer Fahrzeuge**

Key Account Manager, Händler, MO und MPC können einem Flottenkunden Verträge für mehrere identische Fahrzeuge (gleiche Fahrzeugkonfiguration bzw. gleiche SA-Codes) in einem Zug anbieten. Dabei lassen sich die Abläufe als Build to Order (BTO) oder Build to Stock (BTS) kennzeichnen. Voraussetzung ist, dass Produkte und Sonderkonfigurationen für gewerbliche Flottenkunden verfügbar sind. Die Massenerfassung steht für drei Abläufe zur Verfügung: Fahrgestellnummer, VIN oder FIN mit vorhandenem Datum der Erstzulassung (FRD), Build to Order und Build to Stock. Der Baumaster-Ablauf wird nicht unterstützt.

Der Einstieg erfolgt über den Geschäftsablauf „Contract Generation“ und dort über das Contract Proposal. Zur Erfassung der Fahrzeugdaten wählen Sie zunächst den Kundentyp „Commercial Fleet“. Optional können Sie eine Branche auswählen; der Standardwert lautet „Not Relevant“. Anschließend geben Sie eine Kennung ein, zum Beispiel Bestellnummer, Fahrgestellnummer, VIN, FIN oder Baumaster, und ergänzen die weiteren Angaben. Danach wählen Sie das Produkt und schließen die Produktkonfiguration ab. Über die Schaltfläche „Add Multiple Vehicles“ fügen Sie eine Liste von Fahrzeugen hinzu, entweder manuell, per Excel-Upload oder per Copy-and-paste. Mit einem Klick auf das Häkchen starten Sie die erstmalige Validierung der Fahrzeuge. Haben Sie Angaben korrigiert, senden Sie die Fahrzeuge mit „Update“ erneut ab.

Die Fahrzeugdaten werden gegen das System Vedoc (Stream 1) validiert. Hat ein Händler zu einer Fahrgestellnummer ein Erstzulassungsdatum eingegeben, das vom Wert in Vedoc abweicht, wird das manuell eingegebene Datum mit dem Vedoc-Wert überschrieben. Das Datum ist danach für Sie nicht mehr bearbeitbar, genau wie bisher bei einem einzelnen Fahrzeug. Die betroffenen Zeilen werden mit einem blauen Häkchen markiert, und es erscheint ein Hinweisbanner mit folgendem Text: „The vehicles with the First Registration date validated by VeDoc are marked with a check. This means the inputed dates you have entered have been overwritten by the system and you are not allowed to make any changes to this information.“

Wie bei einem einzelnen Fahrzeug erkennt das System auch bei mehreren Fahrzeugen anhand der eingegebenen oder hochgeladenen Werte, ob es sich um einen BTO- oder BTS-Fall handelt. Bei einem Upload dürfen einzelne Felder der Datei leer sein. Der Ablauf ergibt sich aus folgenden Kombinationen:

Sind Fahrgestellnummer, Erstzulassungsdatum, aktueller Kilometerstand und Kennzeichen alle vorhanden, wird der Fahrgestellnummern-Ablauf angewendet. Ist die Fahrgestellnummer vorhanden, das Erstzulassungsdatum leer, der Kilometerstand 0 und das Kennzeichen leer, wird der Build-to-Stock-Ablauf angewendet. Ist die Bestellnummer vorhanden und sind Erstzulassungsdatum, Kilometerstand und Kennzeichen leer, wird der Build-to-Order-Ablauf angewendet. Bei BTS und BTO werden die fehlenden Fahrzeugdaten nach der Bestätigung ergänzt.

Die Copy-and-paste-Funktion für mehrere Fahrzeuge ist für PI12 vorgesehen. Damit können Sie mehrere Datensätze auf einmal, ähnlich wie in Microsoft Excel, in die Spalten Kennung, Erstzulassungsdatum, Kilometerstand und Kennzeichen einfügen. Beim Einfügen werden dieselben Formatprüfungen wie beim Datei-Upload durchgeführt. Erst wenn alle Formatfehler behoben sind, wird die Schaltfläche „Bestätigen“ aktiviert, mit der die Daten zur Fahrzeugvalidierung an Stream 1 gesendet werden.

Haben Sie auf der Seite „Add Multiple Vehicles“ Fahrzeuge eingegeben und klicken dann auf das „X“ oder auf ein anderes Modul wie das Vertragsmanagement bzw. an eine beliebige Stelle außerhalb der Seite, erscheint eine Warnung: „The vehicles you have entered are not saved to this product configuration. The information you have entered will not be updated and will be lost. Are you sure you want to proceed?“ Wenn Sie fortfahren, gehen die eingegebenen Daten verloren.
