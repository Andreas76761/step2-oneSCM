## [Batch 647.1] Gewerbekunden-Stammdaten: Suche und Filterung

Im Bereich „Customer Management" steht Ihnen im Reiter „Commercial Customer" eine Suche für Gewerbekunden zur Verfügung. Sie können sowohl als Market-Operation-Benutzer als auch als MPC-Benutzer nach Gewerbekundendaten suchen. Beim Öffnen des Reiters wird zunächst eine leere Ergebnisseite angezeigt.

Als Suchfelder und Filter stehen Name, Debitorennummer, USt-IdNr. (VAT ID), Postleitzahl und Ort zur Verfügung. Für eine Suche geben Sie mindestens einen der Werte Name oder USt-IdNr. ein. Optional ergänzen Sie weitere Filter wie Debitorennummer, Postleitzahl und/oder Ort. Die Felder und Filter sind miteinander durch ein „Und" verknüpft und werden in der Reihenfolge angewendet, in der sie in der Oberfläche angezeigt werden. Sind bei einem Filter mehrere Auswahlen möglich, erscheinen die ausgewählten Werte als Chips in der Reihenfolge der Oberfläche. Wenn Sie einen Filter mit Einfachauswahl ändern, bleiben alle anderen angewendeten Filter unverändert.

Mit der Schaltfläche „Search for customers" lassen Sie sich die Ergebnisse entsprechend Ihren Angaben anzeigen. Im Pop-up der weiteren Filter übernimmt „Apply" die dort eingegebenen Werte in die Suche, während „Cancel" die dort eingegebenen Werte zurücksetzt. Möchten Sie eine neue Suche beginnen, wählen Sie „Reset". Dadurch werden alle Felder und Filter geleert und sind für eine neue Suche bereit. Liefert die Suche keine Treffer, erscheint anstelle der Ergebnisse eine entsprechende Meldung.

Die Oberfläche entspricht den Vorgaben des Mercedes-Benz Workbench und dem mit dem Kunden abgestimmten UI-Design.

## [Batch 744.2] Suche und Filter

Die Suche ist über vier Felder möglich: Vertragsnummer, Kundenname, Fahrgestellnummer und Kennzeichen. Wer weitere Suchkriterien verwenden möchte, klickt auf „More Filter“. Tritt beim Abrufen der Daten ein Fehler auf, erscheint eine Hinweismeldung mit dem Text „No data available“.

## [Batch 1243.2] Suche und Filter

Der obere Bereich der Seite trägt den Titel „Search Products". Er enthält ein Suchfeld mit dem Platzhalter „Product Name". Mit einem X-Symbol im Feld lässt sich der eingegebene Text löschen. Die Suche bezieht sich auf den Produktnamen: Ein Produkt wird gefunden, wenn der Suchbegriff an beliebiger Stelle im Namen vorkommt. Die Suche starten Sie mit der Schaltfläche „Search & Filter". Mit „Reset" setzen Sie alle Suchbegriffe, Filter und das Häkchen für gelöschte Produkte zurück, sodass die Liste wieder ungefiltert angezeigt wird.

Zusätzlich stehen Filter als Mehrfachauswahl-Dropdowns zur Verfügung, deren Inhalte aus dem Blueprint stammen. Verfügbar sind Division (z. B. Passenger Car), Brand (z. B. Mercedes Benz), Blueprint (z. B. Excellent), Assigned Prices (Draft Products – No prices possible, Ready Products – No prices assigned, Prices assigned) sowie Status (Draft, Created, Ready, Published, Deactivated, Deleted). Die Filter bauen aufeinander auf: Eine Auswahl schränkt die Optionen in den nachfolgenden Filtern ein. Wählen Sie beispielsweise Passenger Car, werden im Brand-Filter nur Marken aus diesem Bereich angeboten. Bei der Auswahl in einem Filter werden bereits gesetzte Filter weiterhin berücksichtigt. Über die Schaltfläche „More filters" können weitere Filter ausgewählt und mit „Filter" angewendet werden.

Mit dem Kontrollkästchen „Show deleted products" steuern Sie die Anzeige gelöschter Produkte. Ist es aktiviert, zeigt die Tabelle ausschließlich gelöschte Produkte. Ist es deaktiviert, werden die Produkte in den Status Draft, Created, Ready, Published und Deactivated angezeigt.

## [Batch 1228.6] Technische Grundlage: Elastic Search

Für eine schnelle und effiziente Aufbereitung und Darstellung von Daten in der Benutzeroberfläche wird in oneSCM eine Elastic-Search-Instanz eingesetzt. Sie speichert die DTOs, die in der oneSCM-Oberfläche verwendet werden, und unterstützt das Suchen, Sortieren, Blättern (Pagination) und Filtern. Die Daten in Elastic Search werden regelmäßig mit den Daten aus der Datenbank des jeweiligen Systems aktualisiert.
